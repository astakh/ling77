# Страница настроек - Краткая инструкция

## Что добавлено

✅ Новая страница настроек (`/settings`)
✅ Кнопка перехода с дашборда (иконка шестерёнки ⚙️)
✅ Настройка уровня знания (A1, A2, B1, B2)
✅ Настройка количества слов в уроке (3-15)
✅ Настройка количества уроков в день (1-10)
✅ Выбор словаря для изучения

## Применение изменений

### 1. Применить миграцию базы данных

```bash
cd backend
alembic upgrade head
```

Это добавит поле `words_per_lesson` в таблицу `learning_profiles`.

### 2. Перезапустить backend

```bash
uvicorn main:app --reload
```

### 3. Перезапустить frontend

```bash
npm run dev
```

### 4. Проверить

1. Открыть http://localhost:3000
2. Войти в систему
3. На дашборде нажать на иконку шестерёнки (⚙️) в правом верхнем углу
4. Изменить настройки
5. Нажать "Сохранить настройки"

## API Endpoint

```http
PATCH /settings
Content-Type: application/json

{
  "level": "B1",
  "words_per_lesson": 10,
  "lessons_per_day": 3,
  "dictionary_id": 2
}
```

Все поля опциональны.
