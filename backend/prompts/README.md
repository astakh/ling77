# 📝 Промпты для GigaChat API

В этом каталоге хранятся шаблоны промптов для взаимодействия с GigaChat API.

## Файлы

### `generate_exercise.txt`
Промпт для генерации упражнений (предложений) на основе списка слов.

**Использование:**
- Вызывается в функции `_build_exercise_prompt()` в `backend/llm_client.py`
- Температура: 0.7 (для разнообразия предложений)
- Возвращает: JSON массив с предложениями и переводами

**Переменные:**
- `{level}` - уровень ученика (A1, A2, B1, B2)
- `{clusters_text}` - список групп слов для упражнений

### `evaluate_translation.txt`
Промпт для оценки перевода ученика.

**Использование:**
- Вызывается в функции `_build_evaluate_prompt()` в `backend/llm_client.py`
- Температура: 0.2 (для точности оценки)
- Возвращает: JSON с оценками каждого слова

**Переменные:**
- `{target_sentence}` - английское предложение для перевода
- `{wrapped_user}` - перевод ученика (обёрнут в маркеры для защиты от инъекций)
- `{words_text}` - список целевых слов с переводами

**Формат ответа:**
```json
{
  "evaluations": [
    {
      "word_lemma": "слово",
      "result": "correct|typo|incorrect",
      "user_fragment": "как ученик перевёл это слово"
    }
  ],
  "overall_result": "correct|typo|incorrect",
  "new_suggested_words": ["word1", "word2"]
}
```

## Изменение промптов

Для изменения логики работы LLM:
1. Отредактируйте соответствующий `.txt` файл
2. Перезапустите backend: `uvicorn main:app --reload`
3. Протестируйте изменения

**Важно:**
- Не удаляйте переменные в фигурных скобках `{...}` - они подставляются кодом
- Сохраняйте формат JSON в примерах ответа
- Тестируйте изменения на разных уровнях (A1-B2)

## Защита от инъекций

Перевод ученика оборачивается в маркеры `<<<UT_xxx>>>...<<<UT_xxx>>>` для предотвращения prompt injection атак. LLM инструктируется игнорировать любые команды внутри этих маркеров.
