# ✅ Исправлен алгоритм выбора слов для урока

## Что было исправлено

Алгоритм выбора слов для урока теперь **корректно использует настройки пользователя**:

### ✅ 1. Количество слов из профиля
- **Было:** Захардкожено `8` слов
- **Стало:** Используется `profile.words_per_lesson` из настроек пользователя

### ✅ 2. Фильтрация по словарю
- Слова берутся только из выбранного пользователем словаря (`profile.dictionary_id`)

### ✅ 3. Фильтрация по уровню
- Слова берутся только того уровня, который выбран пользователем (`profile.level`)
- Пользователь с уровнем B1 видит слова уровней A1, A2, B1

## Как работает алгоритм

```
Общее количество слов = words_per_lesson (из настроек)

├─ Due слова (повторение): до 60% от words_per_lesson
│  └─ Минимум 3 слова
│
└─ Новые слова: остаток до words_per_lesson
   └─ Из выбранного словаря
   └─ Уровень <= уровня пользователя
```

**Примеры:**
- `words_per_lesson = 10` → due: до 6, new: 4
- `words_per_lesson = 8` → due: до 5, new: 3
- `words_per_lesson = 5` → due: до 3, new: 2

## Как проверить

### 1. Измените настройки

Откройте настройки (⚙️ на дашборде) и измените:
- "Слов в уроке": например, 10

### 2. Начните новый урок

На дашборде нажмите "Начать урок"

### 3. Проверьте количество слов

На странице превью урока должно быть **10 слов** (или меньше, если нет доступных слов)

### 4. Проверьте в базе данных

```sql
-- Проверить настройки пользователя
SELECT user_id, level, dictionary_id, words_per_lesson
FROM learning_profiles
WHERE user_id = 2;

-- Проверить слова в последнем уроке
SELECT COUNT(*) as total_words
FROM lesson_exercise_words
WHERE exercise_id IN (
    SELECT id FROM lesson_exercises
    WHERE lesson_id = (
        SELECT id FROM lessons
        WHERE learning_profile_id = (
            SELECT id FROM learning_profiles WHERE user_id = 2
        )
        ORDER BY lesson_number DESC
        LIMIT 1
    )
);
```
