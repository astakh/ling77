# Страница настроек пользователя

## Обзор

Добавлена новая страница настроек, доступная с дашборда. Пользователь может настроить:
- Уровень знания языка (A1, A2, B1, B2)
- Количество слов в одном уроке (3-15)
- Количество уроков в день (1-10)
- Словарь для изучения

## Использование

### Для пользователя

1. Перейти на дашборд
2. Нажать на иконку шестерёнки (⚙️) в правом верхнем углу
3. Изменить настройки:
   - Выбрать уровень знания
   - Переместить слайдер "Слов в уроке"
   - Переместить слайдер "Уроков в день"
   - Выбрать словарь из списка
4. Нажать "Сохранить настройки"
5. Автоматический возврат на дашборд через 1 секунду

### Для разработчика

#### API Endpoint

```http
PATCH /settings
Content-Type: application/json
Authorization: Bearer <token>

{
  "level": "B1",
  "words_per_lesson": 10,
  "lessons_per_day": 3,
  "dictionary_id": 2
}
```

Все поля опциональны - можно обновлять только нужные настройки.

#### Ответ

```json
{
  "status": "ok"
}
```

## Миграция базы данных

Для применения изменений необходимо выполнить миграцию:

```bash
cd backend
alembic upgrade head
```

Это добавит колонку `words_per_lesson` в таблицу `learning_profiles` со значением по умолчанию 8 для всех существующих профилей.

## Тестирование

### Frontend

1. Перейти на `/settings`
2. Изменить все настройки
3. Нажать "Сохранить"
4. Проверить, что профиль обновился в store
5. Проверить, что произошёл редирект на `/dashboard`

### Backend

1. Отправить PATCH запрос с разными комбинациями полей
2. Проверить, что профиль обновился в БД
3. Проверить валидацию dictionary_id (несуществующий словарь должен вернуть 404)
4. Проверить, что опциональные поля работают (можно обновлять только level)

### Интеграция

1. Изменить настройки через UI
2. Начать новый урок
3. Проверить, что используются новые настройки:
   - Правильный уровень слов
   - Правильное количество слов
   - Слова из выбранного словаря

## Ошибки

### Возможные ошибки

1. **404 Learning profile not found**
   - У пользователя нет профиля обучения
   - Решение: пройти онбординг

2. **404 Dictionary not found**
   - Указан несуществующий словарь
   - Решение: выбрать существующий словарь из списка

3. **401 Unauthorized**
   - Неверный или отсутствующий токен
   - Решение: войти в систему
