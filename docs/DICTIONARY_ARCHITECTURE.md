# 📚 Архитектура словарей WordFlow

## 🎯 Ключевые принципы

### 1. Словари — ТЕМАТИЧЕСКИЕ, не по уровню

Словари группируют слова по **тематике**, а не по уровню сложности:
- 📚 Общий словарь
- 💻 IT и технологии
- ✈️ Путешествия
- 💼 Бизнес и работа
- 🍽️ Еда и рестораны
- 🏥 Медицина и здоровье
- 💬 Повседневное общение

### 2. Уровень — свойство СЛОВА, не словаря

Каждое слово имеет свой уровень (`A1`, `A2`, `B1`, `B2`). Один словарь может содержать слова разных уровней.

**Пример:** Словарь "IT и технологии" содержит:
- `server` (A2) — базовое слово
- `algorithm` (B1) — среднее слово
- `stakeholder` (B2) — сложное слово

### 3. Уровень пользователя фильтрует слова

Уровень пользователя (`learning_profiles.level`) определяет, какие слова ему показываются:
- Пользователь **A1** видит только слова уровня **A1**
- Пользователь **B1** видит слова уровней **A1, A2, B1**
- Пользователь **B2** видит слова всех уровней

### 4. Слово может быть в нескольких словарях

Одно слово может входить в несколько словарей одновременно через связь M:N.

**Пример:** Слово `contract` (B1):
- 📚 Общий словарь
- 💼 Бизнес и работа
- ✈️ Путешествия (визовые контракты)

## 🗄️ Структура БД

```
┌─────────────────────────┐
│      dictionaries       │  ← Тематические словари
├─────────────────────────┤
│ id (PK)                 │
│ name                    │  ← "IT и технологии"
│ description             │
│ category                │  ← "it", "travel", "business"...
│ is_active               │
└────────────┬────────────┘
             │
             │  M:N
             │
┌────────────┴────────────┐
│    dictionary_words     │  ← Связующая таблица
├─────────────────────────┤
│ id (PK)                 │
│ dictionary_id (FK)      │
│ word_id (FK)            │
│ UNIQUE(dict_id, word_id)│
└────────────┬────────────┘
             │
             │  M:N
             │
┌────────────┴────────────┐
│         words           │  ← Уникальные слова
├─────────────────────────┤
│ id (PK)                 │
│ lemma                   │  ← "algorithm"
│ lemma_key               │  ← нормализованный ключ
│ pos                     │  ← "noun", "verb"...
│ level                   │  ← A1/A2/B1/B2 (свойство слова!)
│ translations (JSONB)    │
│ UNIQUE(lemma_key, pos)  │
└─────────────────────────┘

┌─────────────────────────┐
│   learning_profiles     │  ← Профиль пользователя
├─────────────────────────┤
│ user_id                 │
│ level                   │  ← Уровень ПОЛЬЗОВАТЕЛЯ (A1-B2)
│ dictionary_id (FK)      │  ← Выбранный словарь
│ last_lesson_number      │
└─────────────────────────┘
```

## 🔄 Логика подбора слов для урока

```
1. Берём dictionary_id из профиля пользователя
2. Находим все слова в этом словаре (через dictionary_words)
3. Фильтруем по уровню слова <= уровню пользователя
4. Приоритет:
   - due слова (те, что пора повторять)
   - новые слова (которых ещё нет в user_words)
5. Детерминированный рандом для воспроизводимости
```

**Пример:**
- Пользователь: уровень B1, словарь "IT"
- В словаре "IT" есть: `server` (A2), `algorithm` (B1), `framework` (B2)
- Пользователь увидит: `server` (A2) и `algorithm` (B1)
- `framework` (B2) — НЕ покажется, т.к. уровень слова > уровня пользователя

## 📥 Импорт слов

### Скрипт `import_words.py`

При импорте слова автоматически добавляются:
1. В указанный словарь
2. В "Общий словарь" (если он существует)

```bash
# Импорт в тематический словарь
python scripts/import_words.py --dictionary-name "IT и технологии"

# Слова автоматически попадут и в "Общий словарь"
```

### Формат `words.json`

```json
[
  {
    "lemma": "algorithm",
    "pos": "noun",
    "level": "B1",          ← Уровень СЛОВА
    "translations": ["алгоритм"]
  }
]
```

## 🎨 UI: Страница словарей

Пользователь видит:
- Список тематических словарей
- Фильтр по категориям (IT, Путешествия, Бизнес...)
- Количество слов в каждом словаре
- Распределение слов по уровням (A1/A2/B1/B2)

При выборе словаря:
- Новые уроки будут использовать слова из этого словаря
- Уровень пользователя фильтрует слова по сложности

## ✅ Проверка соответствия ТЗ

| Требование | Реализация |
|------------|------------|
| Несколько словарей | ✅ Тематические + общий |
| Выбор/смена словаря | ✅ Через UI |
| Слово в нескольких словарях | ✅ M:N через dictionary_words |
| Словари не делятся по уровню | ✅ Словари только тематические |
| Уровень — свойство слова | ✅ Поле `level` в таблице `words` |
| Уровень пользователя фильтрует | ✅ В логике подбора слов |

## 🚀 Быстрый старт

```bash
# 1. Пересоздать БД (если была старая структура)
psql -h your-server -U postgres -c "DROP DATABASE IF EXISTS wordflow;"
psql -h your-server -U postgres -c "CREATE DATABASE wordflow WITH ENCODING = 'UTF8';"

# 2. Применить миграции
cd backend
alembic upgrade head

# 3. Заполнить словари
python scripts/seed.py

# 4. Запустить backend
uvicorn main:app --reload
```

## 📝 Резюме

**Старая (неправильная) архитектура:**
- Словари по уровням: "A1", "A2", "B1", "B2"
- Слово принадлежит одному словарю

**Новая (правильная) архитектура:**
- Словари тематические: "IT", "Путешествия", "Бизнес"...
- Слово может быть в нескольких словарях
- Уровень — свойство слова и пользователя
- Пользователь выбирает тематику, уровень фильтрует автоматически
