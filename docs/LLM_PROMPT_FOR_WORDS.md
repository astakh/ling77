# 🤖 Промпт для LLM: Генерация словаря слов

## Промпт для ChatGPT / Claude / GigaChat

```
Создай JSON-файл со списком английских слов для изучения. 

ТРЕБОВАНИЯ:
- Формат: JSON-массив объектов
- Каждое слово должно содержать поля:
  * "lemma" - начальная форма слова (строка)
  * "pos" - часть речи: "noun", "verb", "adjective", "adverb" (строка)
  * "level" - уровень: "A1", "A2", "B1" или "B2" (строка)
  * "translations" - массив русских переводов (1-3 варианта)

- Количество слов: [УКАЖИТЕ КОЛИЧЕСТВО, например: 50]
- Уровень: [УКАЖИТЕ УРОВЕНЬ, например: A1]
- Тематика: [УКАЖИТЕ ТЕМУ, например: "еда и напитки" или "общие слова"]

ФОРМАТ ВЫВОДА:
Только валидный JSON, без пояснений и markdown-разметки.

ПРИМЕР:
[
  {
    "lemma": "house",
    "pos": "noun",
    "level": "A1",
    "translations": ["дом", "жилище"]
  },
  {
    "lemma": "run",
    "pos": "verb",
    "level": "A1",
    "translations": ["бежать", "бегать"]
  },
  {
    "lemma": "big",
    "pos": "adjective",
    "level": "A1",
    "translations": ["большой", "крупный"]
  }
]

ВАЖНО:
- Используй только валидный JSON
- lemma должна быть в начальной форме (единственное число для nouns, infinitive для verbs)
- Переводы должны быть точными и употребимыми
- Избегай дубликатов (одинаковых lemma + pos)
- Слова должны соответствовать указанному уровню
```

## 🔧 Постобработка

После получения ответа от LLM:

1. **Сохрани в файл `words.json`** в папке `backend/`

2. **Проверь валидность JSON:**
   ```bash
   # Linux/Mac
   cat words.json | python -m json.tool > /dev/null && echo "✅ Valid JSON" || echo "❌ Invalid JSON"
   
   # Windows PowerShell
   Get-Content words.json | ConvertFrom-Json | Out-Null; if ($?) { Write-Host "✅ Valid JSON" } else { Write-Host "❌ Invalid JSON" }
   ```

3. **Импортируй в словарь:**
   ```bash
   cd backend
   python scripts/import_words.py --dictionary-name "Новый словарь" --dry-run
   ```

4. **Если всё ок, убери `--dry-run`:**
   ```bash
   python scripts/import_words.py --dictionary-name "Новый словарь"
   ```

## 💡 Советы

### Качество переводов
- Указывай 2-3 варианта перевода для многозначных слов
- Первый перевод должен быть самым частотным
- Избегай разговорных вариантов для учебных слов

### Разметка частей речи
- `noun` - существительные
- `verb` - глаголы (в инфинитиве без "to")
- `adjective` - прилагательные
- `adverb` - наречия

### Уровни
- **A1** - базовые слова (100-200 самых частотных)
- **A2** - повседневная лексика (500-1000 слов)
- **B1** - свободное общение (1000-2000 слов)
- **B2** - продвинутый уровень (2000+ слов)

### Проверка дубликатов
Скрипт автоматически проверяет дубликаты по комбинации `lemma + pos`. 
Если слово уже есть в словаре, оно будет пропущено.

## 🎯 Готовые шаблоны

### Шаблон 1: Тематический словарь
```
Создай JSON со словами на тему "[ТЕМА]" уровня [УРОВЕНЬ].
Включи 50 слов: 20 nouns, 15 verbs, 10 adjectives, 5 adverbs.
Формат: массив объектов с полями lemma, pos, level, translations.
Только валидный JSON.
```

### Шаблон 2: Расширение существующего словаря
```
У меня есть словарь уровня [УРОВЕНЬ] с [КОЛИЧЕСТВО] слов.
Добавь ещё 30 слов той же тематики, которых ещё нет в списке.
Формат: JSON-массив с полями lemma, pos, level, translations.
Только валидный JSON.
```

### Шаблон 3: Слова из текста
```
Извлеки из следующего текста сложные английские слова и создай JSON-словарь:

"[ТЕКСТ]"

Для каждого слова укажи:
- lemma (начальная форма)
- pos (часть речи)
- level (уровень A1-B2)
- translations (русские переводы)

Только валидный JSON-массив.
```
