# 📚 Создание универсального словаря

## Что это?

**Универсальный словарь** содержит **базовую лексику** для повседневного общения без специальной терминологии.

### Отличие от "Общего словаря":

| Словарь | Назначение | Видимость | Содержимое |
|---------|-----------|-----------|------------|
| **Общий словарь** | Технический | ❌ Скрыт от пользователей | ВСЕ слова из всех словарей (включая спецтермины) |
| **Универсальный словарь** | Для пользователей | ✅ Доступен | Только базовая лексика без спецтерминов |

## Что включено в универсальный словарь

### A1 - Базовый уровень (~60 слов)
**Существительные:**
- time (время), year (год), people (люди)
- day (день), night (ночь), week (неделя)
- house (дом), room (комната), water (вода)
- work (работа), money (деньги), book (книга)

**Глаголы:**
- be (быть), have (иметь), do (делать)
- go (идти), see (видеть), know (знать)
- want (хотеть), give (давать), use (использовать)

**Прилагательные:**
- good (хороший), new (новый), old (старый)
- big (большой), small (маленький), important (важный)

### A2 - Элементарный уровень (~60 слов)
**Существительные:**
- family (семья), student (студент), country (страна)
- school (школа), food (еда), health (здоровье)
- morning (утро), teacher (учитель), art (искусство)

**Глаголы:**
- understand (понимать), remember (помнить), learn (учиться)
- meet (встречать), help (помогать), start (начинать)
- write (писать), read (читать), play (играть)

**Прилагательные:**
- beautiful (красивый), happy (счастливый), sad (грустный)
- easy (легкий), difficult (трудный), fast (быстрый)

### B1 - Средний уровень (~80 слов)
**Существительные:**
- opportunity (возможность), relationship (отношения)
- experience (опыт), knowledge (знание), success (успех)
- strategy (стратегия), quality (качество), skill (навык)

**Глаголы:**
- achieve (достигать), contribute (вносить вклад)
- encourage (поощрять), evaluate (оценивать)
- recommend (рекомендовать), support (поддерживать)

**Прилагательные:**
- effective (эффективный), independent (независимый)
- professional (профессиональный), significant (значительный)

## Как создать словарь

### Шаг 1: Примените миграцию

```bash
cd backend
alembic upgrade head
```

Это добавит поле `is_public` в таблицу `dictionaries` и скроет "Общий словарь" от пользователей.

### Шаг 2: Запустите скрипт

```bash
cd backend
python scripts/create_universal_dictionary.py
```

### Шаг 3: Проверьте результат

Вы увидите:
```
✅ Создан словарь 'Универсальный словарь' (id=X)
   Описание: Базовая лексика для повседневного общения без специальной терминологии
   Категория: general
   Доступен для пользователей: True

📊 Статистика:
   Всего слов в списке: 200
   Добавлено новых слов: 200
   Пропущено (уже были в словаре): 0

✅ Готово!
   Словарь 'Универсальный словарь' содержит 200 слов

💡 Теперь пользователи могут выбрать этот словарь в настройках
💡 Этот словарь содержит только базовую лексику без специальных терминов
```

### Шаг 4: Проверьте в настройках

1. Откройте настройки пользователя (⚙️ на дашборде)
2. Найдите "Универсальный словарь" в списке
3. Выберите его
4. Начните урок - будут использоваться только базовые слова

## Проверка в админке

1. Откройте `http://localhost:3000/#/admin/login`
2. Войдите с паролем из `.env`
3. Перейдите в "Словари"
4. Вы увидите:
   - ✅ "Универсальный словарь" (is_public=True)
   - ❌ "Общий словарь" (is_public=False) - скрыт от пользователей
   - ✅ "IT и технологии", "Путешествия", "Бизнес и работа" (is_public=True)

## Примеры слов

- time (время)
- work (работа)
- important (важный)
- understand (понимать)

### НЕ в универсальном словаре (в тематических):
- algorithm (IT)

- departure (Путешествия)

## Добавление новых слов

Если хотите добавить больше слов в универсальный словарь:

1. Откройте `backend/scripts/create_universal_dictionary.py`
2. Добавьте новые слова в список `UNIVERSAL_WORDS`
3. Запустите скрипт снова

Формат:
```python
{"lemma": "word", "pos": "noun", "level": "A1", "translations": ["перевод"]}
```

## Скрытие других словарей

Если нужно скрыть любой словарь от пользователей:

```sql
-- В psql
UPDATE dictionaries SET is_public = false WHERE name = 'Название словаря';
```

Или через админку (в разработке).

## Показ скрытых словарей

Если нужно показать скрытый словарь:

```sql
-- В psql
UPDATE dictionaries SET is_public = true WHERE name = 'Название словаря';
```

## API изменения

### Для пользователей

**GET /dictionaries** - возвращает только публичные словари:
```python
query = select(Dictionary).where(
    Dictionary.is_active == True,
    Dictionary.is_public == True  # Фильтр
)
```

### Для администраторов

**GET /admin/dictionaries** - возвращает ВСЕ словари (включая скрытые):
```python
result = await session.execute(
    select(Dictionary).order_by(Dictionary.id)
)
```

## Troubleshooting

### Ошибка: "Общий словарь" виден пользователям

**Решение:**
```bash
cd backend
alembic upgrade head
```

Миграция автоматически скроет "Общий словарь".

### Ошибка: "Универсальный словарь" не создан

**Причина:** Словарь уже существует

**Решение:** Скрипт пропустит создание и покажет:
```
⚠️  Словарь 'Универсальный словарь' уже существует (id=X)
   Пропускаем создание.
```

### Ошибка: Миграция не применяется

**Решение:**
```bash
cd backend
alembic current  # Проверить текущую версию
alembic upgrade head  # Применить все миграции
```
