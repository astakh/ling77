# Админ-панель для управления словарями

## Обзор

Создана полноценная админ-панель для управления словарями с возможностью:
- Просмотра списка всех словарей
- Просмотра слов в каждом словаре
- Удаления словарей
- Редактирования словарей (в разработке)

## Доступ к админке

### URL
- Вход: `http://localhost:3000/#/admin/login`
- Список словарей: `http://localhost:3000/#/admin/dictionaries`
- Просмотр слов: `http://localhost:3000/#/admin/dictionaries/:id`

### Пароль по умолчанию
Пароль хранится в `backend/.env`:
```env
ADMIN_PASSWORD=admin123
```

**Важно:** Измените пароль перед использованием в production!

## Backend API

### Аутентификация

#### POST /admin/login
Вход в админку по паролю.

**Request:**
```json
{
  "password": "admin123"
}
```

**Response:**
```json
{
  "success": true,
  "token": "admin_token_admin123"
}
```

Токен сохраняется в `localStorage` как `admin_token` и используется для всех последующих запросов.

### Управление словарями

#### GET /admin/dictionaries
Получить список всех словарей с количеством слов.

**Headers:**
```
Authorization: Bearer admin_token_admin123
```

**Response:**
```json
[
  {
    "id": 1,
    "name": "Общий словарь",
    "description": "Все слова приложения",
    "category": "general",
    "words_count": 65
  },
  {
    "id": 2,
    "name": "IT и технологии",
    "description": "Словарь для IT-специалистов",
    "category": "it",
    "words_count": 15
  }
]
```

#### GET /admin/dictionaries/{id}
Получить информацию о конкретном словаре.

**Response:**
```json
{
  "id": 1,
  "name": "Общий словарь",
  "description": "Все слова приложения",
  "category": "general"
}
```

#### GET /admin/dictionaries/{id}/words
Получить все слова в словаре.

**Response:**
```json
[
  {
    "id": 1,
    "lemma": "house",
    "pos": "noun",
    "level": "A1",
    "translations": ["дом", "жилище"]
  },
  {
    "id": 2,
    "lemma": "water",
    "pos": "noun",
    "level": "A1",
    "translations": ["вода"]
  }
]
```

#### DELETE /admin/dictionaries/{id}
Удалить словарь и все связи с словами.

**Response:**
```json
{
  "success": true,
  "message": "Словарь удален"
}
```

**Важно:** Это действие нельзя отменить!

#### PUT /admin/dictionaries/{id}
Обновить информацию о словаре.

**Request:**
```json
{
  "name": "Новое название",
  "description": "Новое описание",
  "category": "general"
}
```

**Response:**
```json
{
  "id": 1,
  "name": "Новое название",
  "description": "Новое описание",
  "category": "general"
}
```

## Использование

### 1. Вход в админку

1. Перейдите на `http://localhost:3000/#/admin/login`
2. Введите пароль из `backend/.env` (по умолчанию: `admin123`)
3. Нажмите "Войти"
4. Вы будете перенаправлены на список словарей

### 2. Просмотр списка словарей

На странице списка словарей вы увидите:
- **Статистику:**
  - Всего словарей
  - Всего слов
  - Количество категорий
- **Список словарей** с:
  - Названием
  - Категорией (с иконкой)
  - Описанием
  - Количеством слов
  - Кнопками действий

### 3. Просмотр слов в словаре

1. Нажмите на иконку 👁️ рядом со словарем
2. Вы увидите:
  - Информацию о словаре
  - Количество слов
  - Поле поиска
  - Список всех слов с:
    - Леммой
    - Частью речи (сущ., гл., прил., нар.)
    - Уровнем (A1, A2, B1, B2) с цветными бейджами
    - Переводами

### 4. Удаление словаря

1. Нажмите на иконку 🗑️ рядом со словарем
2. Подтвердите удаление в модальном окне
3. Словарь и все связи с словами будут удалены

**Важно:** Это действие нельзя отменить!

### 5. Выход из админки

1. Нажмите кнопку "Выйти" в правом верхнем углу
2. Токен будет удален из localStorage
3. Вы будете перенаправлены на страницу входа

## Безопасность

### Текущая реализация
- Простая проверка пароля
- Токен хранится в localStorage
- Токен передается в заголовке Authorization

### Рекомендации для production
1. **Измените пароль** в `backend/.env`
2. **Используйте JWT токены** с ограниченным сроком действия
3. **Добавьте rate limiting** для endpoint'а `/admin/login`
4. **Используйте HTTPS** для всех запросов
5. **Добавьте логирование** всех действий администратора
6. **Реализуйте роли** (superadmin, admin, moderator)

## Тестирование

### 1. Проверка входа
```bash
# Правильный пароль
curl -X POST http://localhost:8000/admin/login \
  -H "Content-Type: application/json" \
  -d '{"password": "admin123"}'

# Неправильный пароль
curl -X POST http://localhost:8000/admin/login \
  -H "Content-Type: application/json" \
  -d '{"password": "wrong"}'
```

### 2. Проверка получения словарей
```bash
curl -X GET http://localhost:8000/admin/dictionaries \
  -H "Authorization: Bearer admin_token_admin123"
```

### 3. Проверка получения слов
```bash
curl -X GET http://localhost:8000/admin/dictionaries/1/words \
  -H "Authorization: Bearer admin_token_admin123"
```

### 4. Проверка удаления словаря
```bash
curl -X DELETE http://localhost:8000/admin/dictionaries/1 \
  -H "Authorization: Bearer admin_token_admin123"
```
