# Последствия удаления словаря

## Что происходит при удалении

### ✅ Удаляется:
1. **Запись из таблицы `dictionaries`** - сам словарь
2. **Все связи в таблице `dictionary_words`** - связи этого словаря со словами

### ❌ НЕ удаляется:
1. **Сами слова в таблице `words`** - они остаются в базе данных
   - Слова могут использоваться в других словарях
   - Прогресс пользователей по этим словам сохраняется
2. **Связи пользователей со словами в `user_words`** - прогресс изучения не теряется
3. **Уроки и упражнения** - история занятий сохраняется

### ⚠️ Влияние на пользователей:

**Если словарь был активным у пользователя:**
- Поле `dictionary_id` в `learning_profiles` сбрасывается в `NULL`
- Пользователь не сможет начинать новые уроки
- Нужно вручную выбрать другой словарь через настройки
- Система предупредит администратора о количестве затронутых пользователей

**Пример:**
```
До удаления:
- Словарь "IT и технологии" (id=2)
- 5 пользователей используют этот словарь как активный

После удаления:
- Словарь удален
- Все связи со словами удалены
- У 5 пользователей dictionary_id = NULL
- Им нужно выбрать новый словарь в настройках
```

## Логирование

При удалении словаря, который используется пользователями, в логах backend появится предупреждение:

```
⚠️ Dictionary 2 is used by 5 users. Their dictionary_id will be reset to NULL.
```

## API Response

При удалении словаря API возвращает информацию о затронутых пользователях:

```json
{
  "success": true,
  "message": "Словарь удален",
  "affected_users": 5
}
```

## Frontend уведомления

### При удалении словаря, который НЕ используется:
```
Словарь "IT и технологии" успешно удален.
```

### При удалении словаря, который ИСПОЛЬЗУЕТСЯ:
```
Словарь "IT и технологии" удален.

⚠️ Внимание: 5 пользователь(ей) использовали этот словарь.
Их активный словарь сброшен. Им нужно выбрать новый словарь в настройках.
```

## Рекомендации перед удалением

### 1. Проверьте использование словаря
Перед удалением проверьте:
- Сколько пользователей используют этот словарь
- Есть ли у них прогресс изучения
- Можно ли перенести их на другой словарь

### 2. Альтернативы удалению
Вместо удаления рассмотрите:
- **Деактивацию** - добавить поле `is_active` в таблицу `dictionaries`
- **Архивацию** - переместить в архив вместо удаления
- **Слияние** - объединить с другим словарем

### 3. Уведомление пользователей
Если словарь удаляется и затрагивает пользователей:
- Отправьте email уведомление
- Покажите сообщение в приложении
- Предложите альтернативные словари

## Примеры сценариев

### Сценарий 1: Удаление неиспользуемого словаря
```
Действие: Удалить словарь "Тестовый словарь"
Последствия:
  ✅ Словарь удален
  ✅ Связи со словами удалены
  ✅ Слова остались в базе
  ✅ Никакие пользователи не затронуты
```

### Сценарий 2: Удаление активного словаря
```
Действие: Удалить словарь "IT и технологии"
Последствия:
  ✅ Словарь удален
  ✅ Связи со словами удалены
  ✅ Слова остались в базе
  ⚠️ 5 пользователей потеряли активный словарь
  ⚠️ Им нужно выбрать новый словарь
  ⚠️ Их прогресс изучения сохранен
```

### Сценарий 3: Слово в нескольких словарях
```
Дано:
  - Слово "algorithm" есть в словарях "Общий" и "IT"
  
Действие: Удалить словарь "IT"
Последствия:
  ✅ Словарь "IT" удален
  ✅ Связь "IT" ↔ "algorithm" удалена
  ✅ Слово "algorithm" осталось в базе
  ✅ Связь "Общий" ↔ "algorithm" сохранена
  ✅ Прогресс пользователей по слову "algorithm" сохранен
```

## Восстановление удаленного словаря

### ❌ Невозможно восстановить напрямую
После удаления словарь и все связи удаляются из базы данных.

### ✅ Возможные варианты:
1. **Восстановить из бэкапа базы данных**
   - Если есть регулярные бэкапы PostgreSQL
   - Восстановить таблицы `dictionaries` и `dictionary_words`

2. **Создать заново**
   - Создать новый словарь с тем же названием
   - Вручную добавить слова через импорт

3. **Импортировать из JSON**
   - Если есть экспортированный JSON со словами
   - Использовать скрипт импорта

## Best Practices

### 1. Регулярные бэкапы
Настройте автоматические бэкапы PostgreSQL:
```bash
# Ежедневный бэкап
pg_dump wordflow > backup_$(date +%Y%m%d).sql
```

### 2. Мягкое удаление
Рассмотрите добавление поля `deleted_at`:
```python
class Dictionary(Base):
    # ...
    deleted_at = Column(DateTime, nullable=True)
    is_active = Column(Boolean, default=True)
```

### 3. Проверка перед удалением
Добавьте API endpoint для проверки использования:
```python
@router.get("/dictionaries/{id}/usage")
async def check_dictionary_usage(id: int):
    """Проверить, используется ли словарь"""
    # Вернуть количество пользователей, уроков и т.д.
```

### 4. Подтверждение с деталями
Показывайте администратору детальную информацию:
```
Вы собираетесь удалить словарь "IT и технологии".

Этот словарь используется:
- 5 пользователями как активный
- В 12 завершенных уроках
- Содержит 45 слов

Продолжить?
```
