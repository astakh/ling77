# 📚 Создание словаря широкой тематики

## Что это?

Словарь широкой тематики содержит **базовую лексику** для повседневного общения без специальной терминологии. Включает:
- ✅ Общие слова (время, люди, места)
- ✅ Базовые глаголы (быть, иметь, делать)
- ✅ Прилагательные (хороший, большой, важный)
- ✅ Повседневную лексику (семья, работа, учеба)
- ❌ НЕ включает специальную терминологию (IT, бизнес, путешествия)

## Как создать словарь

### Шаг 1: Запустите скрипт

```bash
cd backend
python scripts/create_general_dictionary.py
```

### Шаг 2: Проверьте результат

Вы увидите:
```
✅ Создан словарь 'Общий словарь' (id=X)
   Описание: Базовая лексика широкой тематики для повседневного общения
   Категория: general

📊 Статистика:
   Всего слов в списке: 200
   Добавлено новых слов: 200
   Пропущено (уже были в словаре): 0

✅ Готово!
   Словарь 'Общий словарь' содержит 200 слов
```

### Шаг 3: Проверьте в админке

1. Откройте `http://localhost:3000/#/admin/login`
2. Войдите с паролем из `.env`
3. Перейдите в "Словари"
4. Найдите "Общий словарь"
5. Нажмите 👁️ чтобы посмотреть слова

## Что включено в словарь

### A1 - Базовый уровень (~60 слов)
**Существительные:**
- time (время), year (год), people (люди)
- day (день), night (ночь), week (неделя)
- house (дом), room (комната), water (вода)
- work (работа), money (деньги), book (книга)

**Глаголы:**
- be (быть), have (иметь), do (делать)
- go (идти), see (видеть), know (знать)
- want (хотеть), give (давать), use (использовать)

**Прилагательные:**
- good (хороший), new (новый), old (старый)
- big (большой), small (маленький), important (важный)

### A2 - Элементарный уровень (~60 слов)
**Существительные:**
- family (семья), student (студент), country (страна)
- school (школа), food (еда), health (здоровье)
- morning (утро), teacher (учитель), art (искусство)

**Глаголы:**
- understand (понимать), remember (помнить), learn (учиться)
- meet (встречать), help (помогать), start (начинать)
- write (писать), read (читать), play (играть)

**Прилагательные:**
- beautiful (красивый), happy (счастливый), sad (грустный)
- easy (легкий), difficult (трудный), fast (быстрый)

### B1 - Средний уровень (~80 слов)
**Существительные:**
- opportunity (возможность), relationship (отношения)
- experience (опыт), knowledge (знание), success (успех)
- strategy (стратегия), quality (качество), skill (навык)

**Глаголы:**
- achieve (достигать), contribute (вносить вклад)
- encourage (поощрять), evaluate (оценивать)
- recommend (рекомендовать), support (поддерживать)

**Прилагательные:**
- effective (эффективный), independent (независимый)
- professional (профессиональный), significant (значительный)

## Как использовать

### Для пользователей

1. Откройте настройки (⚙️ на дашборде)
2. Выберите "Общий словарь"
3. Начните урок - будут использоваться базовые слова

### Для администраторов

1. Откройте админку
2. Перейдите в "Словари"
3. Найдите "Общий словарь"
4. Просмотрите или отредактируйте слова

## Отличие от тематических словарей

| Общий словарь | Тематические словари |
|---------------|----------------------|
| ✅ Базовая лексика | ✅ Специальная лексика |
| ✅ Повседневные слова | ✅ Профессиональные термины |
| ✅ Для всех уровней | ✅ Для конкретных целей |
| ✅ Универсальный | ✅ IT, Бизнес, Путешествия |

## Примеры слов

### В общем словаре:
- time (время)
- work (работа)
- important (важный)
- understand (понимать)

### НЕ в общем словаре (в тематических):
- algorithm (IT)
- negotiate (Бизнес)
- departure (Путешествия)

## Добавление новых слов

Если хотите добавить больше слов в общий словарь:

1. Откройте `backend/scripts/create_general_dictionary.py`
2. Добавьте новые слова в список `GENERAL_WORDS`
3. Запустите скрипт снова

Формат:
```python
{"lemma": "word", "pos": "noun", "level": "A1", "translations": ["перевод"]}
```

## Удаление словаря

Если нужно удалить словарь:

1. Откройте админку
2. Перейдите в "Словари"
3. Найдите "Общий словарь"
4. Нажмите 🗑️
5. Подтвердите удаление

**Важно:** Сами слова не удалятся, только связи со словарем.

## Troubleshooting

### Ошибка: "Словарь уже существует"
Это нормально! Скрипт проверит и пропустит создание, если словарь уже есть.

### Ошибка: "Не удалось подключиться к БД"
Проверьте:
- PostgreSQL запущен
- Настройки в `backend/.env` корректны
- Виртуальное окружение активировано

### Словарь создан, но слов нет
Проверьте логи скрипта. Возможно, все слова уже были в базе.
