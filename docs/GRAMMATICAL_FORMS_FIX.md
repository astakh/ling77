# Исправление оценки грамматических форм в переводах

## Дата
2026-09-29

## Проблема

LLM оценивал переводы с правильным смыслом, но в другой грамматической форме как неправильные.

**Пример:**
- Слово: `suggest` (предлагать)
- Перевод пользователя: `предложил`
- Оценка LLM: `incorrect` (неправильно)
- Ожидаемая оценка: `correct` (правильно)

**Причина:** LLM сравнивал только леммы (начальные формы) без учёта грамматических форм.

## Решение

Обновлён промпт для LLM в файле `backend/prompts/evaluate_translation.txt`:

### 1. Добавлено уточнение о грамматических формах

```
ВАЖНО: учитывай грамматические формы (время, число, род, падеж и т.д.) - 
если смысл передан правильно, но форма отличается (например, "предложил" 
вместо "предлагать" для "suggest"), это считается ПРАВИЛЬНЫМ переводом
```

### 2. Добавлены примеры правильной оценки

```
ПРИМЕРЫ ПРАВИЛЬНОЙ ОЦЕНКИ:
- "suggest" → "предложил" = correct (правильный смысл, другая грамматическая форма)
- "suggest" → "предлагать" = correct (правильный смысл, инфинитив)
- "suggest" → "предлагаю" = correct (правильный смысл, другая форма)
- "suggest" → "важный" = incorrect (неправильный смысл)
- "suggest" → "предлогаю" = typo (опечатка, правильный смысл)
```

## Изменённые файлы

- `backend/prompts/evaluate_translation.txt` - обновлён промпт для LLM

## Как это работает

### До изменений

LLM получал промпт:
```
Для каждого целевого слова определи:
- "correct": правильный перевод в соответствии с контекстом и значением
- "typo": перевод правильный, но была опечатка
- "incorrect": перевод не правильный или слово вообще остуствует в переведенном предложении
```

Результат: LLM сравнивал только леммы, игнорируя грамматические формы.

### После изменений

LLM получает промпт с уточнением:
```
Для каждого целевого слова определи:
- "correct": правильный перевод в соответствии с контекстом и значением. 
  ВАЖНО: учитывай грамматические формы (время, число, род, падеж и т.д.) - 
  если смысл передан правильно, но форма отличается, это считается ПРАВИЛЬНЫМ переводом
- "typo": перевод правильный по смыслу, но была опечатка (1-2 буквы)
- "incorrect": перевод НЕПРАВИЛЬНЫЙ по смыслу или слово вообще отсутствует

ПРИМЕРЫ ПРАВИЛЬНОЙ ОЦЕНКИ:
- "suggest" → "предложил" = correct
- "suggest" → "предлагать" = correct
- "suggest" → "предлагаю" = correct
- "suggest" → "важный" = incorrect
- "suggest" → "предлогаю" = typo
```

Результат: LLM учитывает грамматические формы и оценивает перевод по смыслу.

- Перевод: `предлагать` → должно быть `correct`

## Преимущества

1. **Более точная оценка** - учитываются грамматические формы
2. **Лучший UX** - пользователь не получает ложных ошибок
3. **Правильное обучение** - фокус на смысле, а не на форме
4. **Примеры в промпте** - LLM лучше понимает задачу

## Обратная совместимость

Изменения касаются только промпта для LLM. Структура данных и логика обработки на backend не изменились, поэтому обратная совместимость сохранена.

## Дополнительные улучшения (опционально)

В будущем можно добавить:

1. **Проверку на backend** - если LLM всё-таки ошибся, можно добавить дополнительную проверку на основе словаря синонимов
2. **Машинное обучение** - обучить модель на примерах правильных/неправильных оценок
3. **Ручная корректировка** - позволить пользователю оспорить оценку LLM

Но текущее решение с улучшенным промптом должно решить большинство проблем.

## Заключение

Обновлённый промпт с примерами и уточнениями о грамматических формах должен значительно улучшить качество оценки переводов. LLM теперь будет учитывать смысл перевода, а не только грамматическую форму.
