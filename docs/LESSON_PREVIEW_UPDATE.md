# Обновление страницы "Состав урока"

## Изменения

### 1. Скрыт перевод для слов на повторении

**Было:**
- Для всех слов отображался перевод

**Стало:**
- Для слов с `isDue = true` (на повторении) перевод НЕ показывается

**Код:**
```tsx

  <div className="text-sm text-gray-500 mt-1">
```

**Стало:**

**Было:**
```

```

**Стало:**
```
В этом уроке {count} слов. Нажмите ✓ если уже знаете слово.
```

## Логика работы

### Слова на повторении (isDue = true)

Когда пользователь нажимает "Знаю слово" для слова на повторении:
1. Слово добавляется в `declinedWords`
2. Страница перезагружается
3. Backend заменяет это слово на другое из словаря
4. Пользователь видит новое слово вместо старого

**Важно:** Это позволяет пользователю пропустить слова, которые он уже хорошо знает, и сосредоточиться на новых или сложных словах.

### Новые слова (isNew = true)

Для новых слов:
- Показывается перевод
- Пользователь может нажать "Знаю слово" если уже знает это слово
- Слово будет заменено на другое

## Визуальные изменения

### Иконки
- Было: `<X className="w-4 h-4" />` (крестик)
- Стало: `<Check className="w-4 h-4" />` (галочка)

### Цвета
- Было: `hover:text-red-500` (красный при наведении)
- Стало: `hover:text-green-500` (зеленый при наведении)

### Бейджи
- Новое слово: зеленый бейдж "новое"
- Повтор: желтый бейдж "повтор"

## Примеры

### Пример 1: Слово на повторении

```
┌─────────────────────────────────────┐
│ house                    [повтор]   │
│                          ✓         │
└─────────────────────────────────────┘
```

Перевод НЕ показывается - пользователь должен вспомнить сам.

### Пример 2: Новое слово

```
┌─────────────────────────────────────┐
│ algorithm                [новое]    │
│ алгоритм                           │
│                          ✓         │
└─────────────────────────────────────┘
```

Перевод показывается - пользователь видит новое слово.

## Преимущества

1. **Лучшее обучение** - пользователь проверяет знания без подсказок
2. **Гибкость** - можно пропустить известные слова
3. **Позитивный UX** - галочка вместо крестика, зеленый цвет вместо красного
4. **Эффективность** - фокус на новых и сложных словах
