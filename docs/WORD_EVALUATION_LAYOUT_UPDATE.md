# Изменения в блоке оценки слов

## Дата
2026-09-29

## Описание изменений

Внесены изменения в отображение блока "📝 Оценка слов" на странице результата упражнения.

## Что изменилось

### 1. Добавлен "Перевод пользователя" перед "Правильный перевод"

**Было:**
- Для правильных ответов показывался только статус "✓ Правильно"
- Для неправильных ответов показывались: "Ваш перевод" и "Правильный перевод"

**Стало:**
- Для всех ответов теперь показываются оба поля:
  - "Перевод пользователя" - что ввёл пользователь
  - "Правильный перевод" - правильный ответ (показывается только для неправильных ответов)

### 2. Изменена структура отображения

**Было:**
```
[иконка] слово
  статус
  Ваш перевод: ...
  Правильный перевод: ...
```

**Стало:**
```
[иконка] слово [статус]
  Перевод пользователя: ...    Правильный перевод: ...
```

### 3. Улучшена визуальная иерархия

- Каждое слово отделено горизонтальной линией
- Иконка и статус теперь в одной строке со словом
- Статус отображается как цветной бейдж
- Переводы расположены в одну строку для компактности
- Для правильных ответов "Правильный перевод" не показывается (чтобы не загромождать)

## Технические детали

### Изменённый файл
- `src/pages/ExercisePage.tsx` (строки 331-388)

### Структура компонента

```tsx
<div className="border-b border-gray-100 last:border-b-0 pb-2 last:pb-0">
  {/* Строка 1: иконка + слово + статус */}
  <div className="flex items-center gap-2 mb-1">
    <div className="icon">...</div>
    <span className="word">...</span>
    <span className="status-badge">...</span>
  </div>
  
  {/* Строка 2: переводы в одну линию */}
  <div className="flex items-center gap-4 text-sm ml-7">
    <div>Перевод пользователя: ...</div>
    {!isCorrect && <div>Правильный перевод: ...</div>}
  </div>
</div>
```

### Цветовая схема

**Правильный ответ:**
- Иконка: зелёная (bg-green-100)
- Статус: зелёный бейдж (bg-green-100 text-green-700)
- Перевод пользователя: зелёный (text-green-600)

**Опечатка:**
- Иконка: жёлтая (bg-amber-100)
- Статус: жёлтый бейдж (bg-amber-100 text-amber-700)
- Перевод пользователя: жёлтый (text-amber-600)

**Неправильный ответ:**
- Иконка: красная (bg-red-100)
- Статус: красный бейдж (bg-red-100 text-red-700)
- Перевод пользователя: красный (text-red-500)


### Неправильный ответ
```
✗ consider [✗ Неправильно]
  Перевод пользователя: важный    Правильный перевод: рассматривать
```

## Преимущества новой структуры

1. **Компактность** - все данные по слову в двух строках вместо четырёх
2. **Читаемость** - чёткая визуальная иерархия
3. **Информативность** - сразу виден перевод пользователя для всех ответов
4. **Эстетичность** - разделители между словами, цветные бейджи для статусов
