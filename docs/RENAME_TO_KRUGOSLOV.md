## Как проверить

### 1. Запустите frontend
```bash
npm run dev
```

### 2. Откройте главную страницу
```
http://localhost:3000/
```

Должна загрузиться landing page с названием "Кругослов"

### 3. Нажмите "Начать бесплатно"
Должны попасть на страницу авторизации `/auth`

### 4. Зарегистрируйтесь или войдите
- Введите email и пароль
- Нажмите "Создать аккаунт" или "Войти"
- Должны попасть на страницу онбординга `/onboarding`

### 5. Пройдите онбординг
- Выберите уровень (A1-B2)
- Нажмите "Начать обучение"
- Должны попасть на дашборд `/dashboard`

### 6. Проверьте дашборд
- Должна отображаться статистика
- Кнопка "Начать урок" должна работать
- Навигация должна работать (словари, мои слова, настройки)

## Структура проекта

```
krugoslov/
├── src/                    # Frontend (React + Vite + TypeScript + Tailwind)
│   ├── api/               # API клиент для backend
│   ├── pages/             # Страницы приложения
│   ├── store/             # Zustand state management
│   ├── data/              # Словарь и предложения (для демо)
│   ├── utils/             # SRS логика, storage helpers
│   └── types.ts           # TypeScript типы
│
└── backend/               # Backend (Python + FastAPI)
    ├── routes/            # API endpoints
    ├── models.py          # SQLAlchemy models
    ├── schemas.py         # Pydantic schemas
    ├── auth.py            # JWT + password hashing
    ├── srs.py             # SRS алгоритм
    ├── llm_client.py      # GigaChat клиент
    └── alembic/           # Database migrations
```
