# Изменение структуры блока "Оценка слов"

## Дата
2026-09-29

## Описание изменений

Перестроена структура отображения блока "📝 Оценка слов" на странице результата упражнения для улучшения читаемости и визуальной иерархии.

## Что изменилось

### Новая структура

**Для каждого слова:**

1. **Строка 1:** Слово слева - Статус справа (в одну строку)
2. **Если неправильно переведено:**
   - **Строка 2:** "Ваш перевод: ..."
   - **Строка 3:** "Правильный перевод: ..."

### Пример отображения

**Правильный перевод:**
```
house                              ✓ Правильно
```

**Опечатка:**
```
beutiful                           ⚠ Опечатка
Ваш перевод: красивый
Правильный перевод: красивый
```

**Неправильный перевод:**
```
consider                           ✗ Неправильно
Ваш перевод: важный
Правильный перевод: рассматривать
```

## Технические детали

### Изменённый файл
- `src/pages/ExercisePage.tsx` (строки 331-373)

### Структура компонента

```tsx
<div className="border-b border-gray-100 last:border-b-0 pb-3 last:pb-0">
  {/* Строка 1: слово - статус */}
  <div className="flex items-center justify-between">
    <span className="font-semibold text-gray-800 text-base">
      {word.surface_form || word.surfaceForm}
    </span>
    <span className={`text-sm font-medium ${colorClass}`}>
      {statusText}
    </span>
  </div>
  
  {/* Если неправильно - показываем переводы */}
  {!isCorrect && (
    <div className="mt-2 space-y-1">
      <div className="text-sm">
        <span className="text-gray-500">Ваш перевод: </span>
        <span className={`font-medium ${colorClass}`}>
          {userFragment || '—'}
        </span>
      </div>
      <div className="text-sm">
        <span className="text-gray-500">Правильный перевод: </span>
        <span className="font-medium text-green-600">
          {word.translation || '—'}
        </span>
      </div>
    </div>
  )}
</div>
```

### Ключевые изменения

1. **Убраны иконки** - статус теперь отображается только текстом (✓/⚠/✗)
2. **Убраны цветные бейджи** - статус теперь просто цветной текст
3. **Выровнено по краям** - слово слева, статус справа (flex justify-between)
4. **Упрощена структура** - переводы отображаются только для неправильных ответов
5. **Увеличен отступ** - между словами теперь pb-3 вместо pb-2 для лучшей читаемости

### Цветовая схема

**Правильный ответ:**
- Статус: зелёный текст (text-green-600)
- Переводы не показываются

**Опечатка:**
- Статус: жёлтый текст (text-amber-600)
- Ваш перевод: жёлтый (text-amber-600)
- Правильный перевод: зелёный (text-green-600)

**Неправильный ответ:**
- Статус: красный текст (text-red-600)
- Ваш перевод: красный (text-red-500)
- Правильный перевод: зелёный (text-green-600)

## Преимущества новой структуры

1. **Чище и проще** - убраны лишние иконки и бейджи
2. **Лучшая читаемость** - слово и статус на одной линии
3. **Меньше визуального шума** - переводы показываются только когда нужно
4. **Более компактно** - для правильных ответов только одна строка
5. **Чёткая иерархия** - сразу видно что правильно, а что нет
