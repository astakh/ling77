# 🏠 Landing Page - Лицевая страница

## Обзор

Создана привлекательная landing page для незарегистрированных пользователей, которая показывает преимущества приложения WordFlow и призывает к регистрации.

## Структура страницы

### 1. Hero секция
- Логотип и название приложения
- Главный заголовок: "Учите английские слова эффективно"
- Подзаголовок с описанием
- Кнопка CTA: "Начать бесплатно"
- Примечание о быстрой регистрации

### 2. Преимущества (Features Grid)
Три карточки с основными возможностями:
- **Интервальное повторение** - научный метод запоминания
- **AI-оценка переводов** - мгновенная обратная связь
- **Тематические словари** - IT, бизнес, путешествия, еда

### 3. Как это работает
Три шага с иконками:
1. Выберите словарь и уровень
2. Проходите уроки каждый день
3. Запоминайте слова навсегда

### 4. Почему WordFlow?
Шесть преимуществ с чекмарками:
- Научный подход
- Экономия времени
- Персонализация
- Мгновенная обратная связь
- Отслеживание прогресса
- Бесплатно

### 5. Final CTA
Яркий блок с градиентом:
- Заголовок: "Готовы начать учить слова?"
- Подзаголовок с призывом
- Кнопка: "Зарегистрироваться бесплатно"

### 6. Footer
Простой футер с копирайтом

## Дизайн

### Цветовая схема
- Основной: Indigo (#4F46E5)
- Акцент: Purple (#9333EA)
- Успех: Green (#16A34A)
- Фон: Gradient (indigo-50 → white → purple-50)

### Типографика
- Заголовки: Bold, крупные размеры (text-5xl, text-3xl, text-xl)
- Основной текст: Regular, серые оттенки (text-gray-600, text-gray-500)
- Акценты: Цветные иконки и кнопки

### Компоненты
- Карточки с тенями и границами
- Круглые иконки в цветных фонах
- Градиентные кнопки с hover эффектами
- Числовые бейджи для шагов

## Роутинг

### Публичные маршруты
- `/` - Landing Page (главная)
- `/auth` - Страница авторизации
- `/admin/login` - Вход в админку

### Защищенные маршруты
Все остальные страницы требуют авторизации:
- `/onboarding`
- `/dashboard`
- `/lesson/preview`
- `/lesson/exercise`
- `/lesson/summary`
- `/vocabulary`
- `/dictionaries`
- `/settings`
- `/admin/dictionaries`
- `/admin/dictionaries/:dictionaryId`

## Навигация

### Кнопки CTA
Все кнопки "Начать бесплатно" и "Зарегистрироваться бесплатно" ведут на `/auth`

### Логика перехода
```typescript
const handleRegister = () => {
  navigate('/auth');
};
```

## Адаптивность

### Mobile-first дизайн
- Grid системы адаптируются под размер экрана
- `md:grid-cols-3` для десктопа
- Одна колонка для мобильных устройств

### Размеры текста
- Заголовки уменьшаются на мобильных
- Кнопки сохраняют размер для удобства нажатия

## Иконки

Используются иконки из `lucide-react`:
- `BookOpen` - логотип приложения
- `Brain` - интервальное повторение
- `Zap` - AI-оценка
- `Target` - тематические словари
- `CheckCircle` - преимущества
- `ArrowRight` - кнопки CTA

## Тестирование

### Проверка страницы
1. Откройте `http://localhost:3000/`
2. Должна загрузиться landing page
3. Проверьте все секции
4. Нажмите на кнопки CTA
5. Должен произойти переход на `/auth`

### Проверка роутинга
- `/` → Landing Page ✅
- `/auth` → Auth Page ✅
- `/dashboard` → Redirect to `/auth` (если не авторизован) ✅
