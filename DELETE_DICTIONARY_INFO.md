# 🗑️ Удаление словаря - Что нужно знать

## Краткий ответ

При удалении словаря:
- ✅ **Удаляется** сам словарь и связи со словами
- ✅ **Сохраняются** сами слова (они могут быть в других словарях)
- ✅ **Сохраняется** прогресс пользователей по этим словам
- ⚠️ **Сбрасывается** активный словарь у пользователей, если они использовали удаляемый словарь

## Подробное объяснение

### Что удаляется:
1. **Запись словаря** из таблицы `dictionaries`
2. **Все связи** этого словаря со словами из таблицы `dictionary_words`

### Что НЕ удаляется:
1. **Сами слова** в таблице `words` - они остаются в базе
   - Пример: слово "algorithm" может быть в словарях "Общий" и "IT"
   - Если удалить "IT", слово "algorithm" останется в "Общий"
   
2. **Прогресс пользователей** в таблице `user_words`
   - Если пользователь изучал слово "algorithm" через словарь "IT"
   - После удаления "IT" прогресс по слову "algorithm" сохраняется
   - Пользователь сможет продолжить изучение через другой словарь

### Влияние на пользователей:

**Если словарь НЕ использовался как активный:**
- ✅ Никаких последствий для пользователей
- ✅ Они могут продолжать учиться как обычно

**Если словарь ИСПОЛЬЗОВАЛСЯ как активный:**
- ⚠️ У пользователей сбрасывается `dictionary_id` в `NULL`
- ⚠️ Они не смогут начинать новые уроки
- ⚠️ Им нужно выбрать новый словарь в настройках
- ✅ Их прогресс изучения сохраняется

## Пример

### До удаления:
```
Словарь "IT и технологии" (id=2)
├── Слова: algorithm, database, server, ...
├── Связи: 15 слов
└── Пользователи:
    - User1 (активный словарь: IT)
    - User2 (активный словарь: IT)
    - User3 (активный словарь: Общий)
```

### После удаления:
```
Словарь "IT и технологии" - УДАЛЕН

Слова в базе:
├── algorithm (остался в "Общий")
├── database (остался в "Общий")
└── server (остался в "Общий")

Пользователи:
├── User1 → dictionary_id = NULL ⚠️ (нужно выбрать новый словарь)
├── User2 → dictionary_id = NULL ⚠️ (нужно выбрать новый словарь)
└── User3 → dictionary_id = 1 ✅ (не затронут)
```

## Уведомления

### В логах backend:
```
⚠️ Dictionary 2 is used by 2 users. Their dictionary_id will be reset to NULL.
```

### В интерфейсе админки:
```
Словарь "IT и технологии" удален.

⚠️ Внимание: 2 пользователь(ей) использовали этот словарь.
Их активный словарь сброшен. Им нужно выбрать новый словарь в настройках.
```

## Рекомендации

### Перед удалением:
1. **Проверьте**, используется ли словарь пользователями
2. **Предупредите** пользователей, если словарь активный
3. **Предложите** альтернативный словарь

### Альтернативы удалению:
- **Деактивация** - добавить поле `is_active` вместо удаления
- **Архивация** - переместить в архив
- **Слияние** - объединить с другим словарем

## Восстановление

### ❌ Невозможно восстановить напрямую
После удаления словарь и связи удаляются из базы.

### ✅ Варианты восстановления:
1. **Из бэкапа PostgreSQL** (если есть)
2. **Создать заново** вручную
3. **Импортировать из JSON** (если есть экспорт)

## Best Practices

1. **Регулярные бэкапы** базы данных
2. **Мягкое удаление** (поле `deleted_at` вместо физического удаления)
3. **Проверка использования** перед удалением
4. **Уведомление пользователей** о важных изменениях
