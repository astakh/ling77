# ✅ Обновление промптов для GigaChat API

## Что изменено

### 1. Промпты вынесены в отдельные файлы

**Было:** Промпты захардкожены в `backend/llm_client.py`

**Стало:** Промпты хранятся в отдельных файлах:
- `backend/prompts/generate_exercise.txt` - генерация упражнений
- `backend/prompts/evaluate_translation.txt` - оценка переводов
- `backend/prompts/README.md` - документация

### 2. Новый промпт для оценки переводов

**Ключевые изменения:**

✅ **Убран `reference_translation`** из промпта
- Раньше LLM видел правильный перевод и сравнивал с ним
- Теперь LLM оценивает перевод самостоятельно, без подсказки

✅ **Добавлена оценка всех слов в предложении**
- LLM должен находить не только ошибки в целевых словах
- Но и другие слова, которые ученик перевёл неправильно

✅ **Улучшен `new_suggested_words`**
- Теперь включает слова, которые ученик пропустил ИЛИ перевёл неправильно
- Исключает служебные слова (артикли, местоимения и т.д.)

✅ **Уточнены критерии оценки**
- `correct` - правильный перевод в соответствии с контекстом
- `typo` - правильный перевод, но с опечаткой
- `incorrect` - неправильный перевод или слово отсутствует

✅ **Добавлено требование указывать "пропущено"**
- Если слово отсутствует в переводе ученика, `user_fragment` должен быть "пропущено"

### 3. Обновлён код

**Файл `backend/llm_client.py`:**

✅ Функция `_build_evaluate_prompt()`:
- Убран параметр `reference_translation`
- Читает промпт из файла `prompts/evaluate_translation.txt`
- Подставляет переменные в шаблон

✅ Функция `_build_exercise_prompt()`:
- Читает промпт из файла `prompts/generate_exercise.txt`
- Подставляет переменные в шаблон

✅ Функция `evaluate_translation()`:
- Убран параметр `reference_translation` из сигнатуры
- Обновлён вызов `_build_evaluate_prompt()`

✅ Функция `_validate_evaluate_response()`:
- Добавлена проверка наличия `new_suggested_words`
- Добавлена проверка наличия `word_lemma` и `user_fragment` в каждой оценке

**Файл `backend/routes/lesson.py`:**

✅ Вызов `evaluate_translation()`:
- Убрана передача `reference_translation`

## Как это работает

### Генерация упражнений

```python
# 1. Читаем шаблон промпта из файла
prompt_template = open('prompts/generate_exercise.txt').read()

# 2. Форматируем группы слов
clusters_text = "Группа 1: house (noun) = дом, жилище\n..."

# 3. Подставляем переменные
prompt = prompt_template.format(level="A1", clusters_text=clusters_text)

# 4. Отправляем в GigaChat с temperature=0.7
response = giga.chat(Chat(messages=[...], temperature=0.7))
```

### Оценка переводов

```python
# 1. Читаем шаблон промпта из файла
prompt_template = open('prompts/evaluate_translation.txt').read()

# 2. Оборачиваем перевод ученика для защиты от инъекций
wrapped_user = f"<<<UT_{random}>>>{user_translation}<<<UT_{random}>>>"

# 3. Форматируем целевые слова
words_text = "house (дом, жилище), water (вода)"

# 4. Подставляем переменные
prompt = prompt_template.format(
    target_sentence="The house is big",
    wrapped_user=wrapped_user,
    words_text=words_text
)

# 5. Отправляем в GigaChat с temperature=0.2
response = giga.chat(Chat(messages=[...], temperature=0.2))

# 6. Валидируем ответ
if _validate_evaluate_response(response):
    # Обрабатываем оценки
    evaluations = response["evaluations"]
    new_suggested_words = response["new_suggested_words"]
```

## Преимущества нового подхода

### 1. Более точная оценка
- LLM не видит правильный перевод, поэтому оценивает объективнее
- Учитывает контекст предложения, а не просто сравнивает с эталоном

### 2. Лучшая обратная связь
- `new_suggested_words` включает все слова с ошибками, не только целевые
- Ученик видит какие слова нужно повторить

### 3. Проще поддерживать
- Промпты в отдельных файлах - легче редактировать
- Не нужно перекомпилировать код для изменения промпта
- Можно A/B тестировать разные версии промптов

### 4. Защита от инъекций
- Перевод ученика оборачивается в маркеры
- LLM инструктируется игнорировать команды внутри маркеров

## Как изменить промпт

1. Откройте нужный файл в `backend/prompts/`
2. Отредактируйте текст промпта
3. Сохраните файл
4. Перезапустите backend: `uvicorn main:app --reload`
5. Протестируйте изменения

**Важно:**
- Не удаляйте переменные `{...}` - они подставляются кодом
- Сохраняйте формат JSON в примерах ответа
- Тестируйте на разных уровнях (A1-B2)

## Тестирование

### Проверка генерации упражнений

```bash
# В терминале backend
python scripts/test_gigachat.py
```

Должно сгенерировать упражнения с новым промптом.

### Проверка оценки переводов

1. Начните урок
2. Введите перевод (правильный или с ошибками)
3. Проверьте логи backend:
   ```
   ✅ Translation evaluated using GigaChat LLM
   ```
4. Проверьте что в ответе есть `new_suggested_words`
