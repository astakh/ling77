# 🎯 Изменения в ExercisePage

## ✅ Что изменено

### 1. Удалена кнопка "Показать перевод-подсказку"
- Удалена кнопка с иконкой глаза
- Удалён блок с переводом-подсказкой
- Удалены неиспользуемые переменные (`showTranslation`, `setShowTranslation`)
- Удалён импорт `Eye` из lucide-react

### 2. Добавлено отображение целевых слов
- Добавлен блок "Слова для перевода"
- Показывает все слова с `isTarget: true`
- Отображает только английские слова (без перевода)
- Слова показаны в виде тегов (чипов)

## 🎨 Визуальное изменение

### Было:
```
┌─────────────────────────────────────┐
│ Переведите предложение              │
│ The house is very important.        │
└─────────────────────────────────────┘

👁️ Показать перевод-подсказку

[Поле ввода перевода]
```

### Стало:
```
┌─────────────────────────────────────┐
│ Переведите предложение              │
│ The house is very important.        │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ СЛОВА ДЛЯ ПЕРЕВОДА                  │
│ [house] [important]                 │
└─────────────────────────────────────┘

[Поле ввода перевода]
```

## 🎯 Преимущества

1. **Чётче видно задачу** — пользователь сразу видит какие слова нужно перевести
2. **Нет подсказок** — пользователь учится переводить самостоятельно
3. **Лучший UX** — слова выделены визуально в виде тегов
4. **Проще интерфейс** — убрана лишняя кнопка

## 🔧 Технические детали

### Удалено:
- `useState` для `showTranslation`
- Кнопка с `Eye` иконкой
- Блок с `referenceTranslation`
- Импорт `Eye` из lucide-react

### Добавлено:
- Блок с целевыми словами из `exercise.words.filter(w => w.isTarget)`
- Отображение `surfaceForm` (lemma слова)
- Стилизация в виде тегов с indigo цветовой схемой
