# 🚀 Админ-панель - Краткое руководство

## Быстрый старт

### 1. Перезапустите backend
```bash
cd backend
uvicorn main:app --reload
```

### 2. Перезапустите frontend
```bash
npm run dev
```

### 3. Войдите в админку
1. Откройте `http://localhost:3000/#/admin/login`
2. Введите пароль: `admin123` (или ваш пароль из `backend/.env`)
3. Нажмите "Войти"

### 4. Управляйте словарями
- Просматривайте список словарей
- Смотрите слова в каждом словаре
- Удаляйте ненужные словари

## Основные возможности

### ✅ Реализовано
- ✅ Вход по паролю
- ✅ Список всех словарей с количеством слов
- ✅ Просмотр слов в словаре
- ✅ Удаление словарей
- ✅ Поиск по словам
- ✅ Статистика (всего словарей, слов, категорий)

### 🔄 В разработке
- 🔄 Редактирование словарей
- 🔄 Добавление новых словарей
- 🔄 Добавление слов в словарь

## Структура админки

```
/admin/login              - Страница входа
/admin/dictionaries       - Список словарей
/admin/dictionaries/:id   - Просмотр слов в словаре
```

## API Endpoints

```
POST   /admin/login                    - Вход
GET    /admin/dictionaries             - Список словарей
GET    /admin/dictionaries/:id         - Информация о словаре
GET    /admin/dictionaries/:id/words   - Слова в словаре
DELETE /admin/dictionaries/:id         - Удалить словарь
PUT    /admin/dictionaries/:id         - Обновить словарь
```

## Безопасность

**Важно:** Измените пароль администратора в `backend/.env`:
```env
ADMIN_PASSWORD=ваш_новый_пароль
```

## Скриншоты

### Страница входа
- Темный градиентный фон
- Белая карточка с формой
- Иконка замка

### Список словарей
- Статистика (3 карточки)
- Таблица словарей с иконками
- Кнопки действий (просмотр, редактирование, удаление)

### Просмотр слов
- Информация о словаре
- Поиск по словам
- Таблица слов с цветными бейджами уровней

## Поддержка

Если возникли проблемы:
1. Проверьте логи backend
2. Проверьте консоль браузера (F12)
3. Убедитесь, что пароль в `.env` совпадает
4. Проверьте, что токен сохранен в localStorage
